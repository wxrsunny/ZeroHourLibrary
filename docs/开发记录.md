## 关键代码对应

- `model/GameTypes.ets`：GameProgress 显式字段、联合类型、createProgress 与 cloneProgress。
- `logic/WorldController.ets`：distanceToRect、canStand、nearbyObject 和 movePlayer；对应 M01—M06、I02、W01。
- `logic/GameEngine.ets`：investigate、submitPuzzle、canFulfilPromise、chooseEnding；对应 I01—I04、P01—P03、E01—E02。
- `storage/SaveCodec.ets` 与 `SaveRepository.ets`：版本和位置校验、存储 Mock、保存队列；对应 S01—S07。
- `pages/Explore.ets`、`components/LibraryMap.ets`、`DirectionPad.ets`：真实自由移动、Canvas 地图、调查与密码面板。
- `entryability/EntryAbility.ets`：入口与前后台状态；对应模拟器后台/重启恢复检查。

源文件位置：`entry/src/main/ets/`。报告应摘录最终代码，结合上述实际 Commit 与测试解释，不使用未经验证的实现描述。

## 实际遇到的问题与修复

1. **ArkUI 内置名称冲突**：组件帮助函数使用 key、direction 名称导致编译冲突，调整为 directionButton、moveDirection 后重新构建成功。
2. **方向键空间和叠层颜色**：默认 padding 与颜色透明度格式影响按钮与弹层显示；调整按钮 padding，采用 ArkUI ARGB 格式，再查看实际截图。
3. **贴住锁门后无法直接入门**：只检查下一步位置，人物停在 y=22 时向外走越出合法范围而不能触发入口。补充当前位置门区检查与向外方向匹配；M06 回归通过，重新构建安装后在模拟器重复解锁和向上入门通过。
4. **保存时序风险**：多个异步保存可能乱序覆盖。保存前序列化为快照，并串行写入；S06 用可控存储替身验证最终写入最后状态。
5. **展示文件上传方式**：MCP 文本文件工具不直接写二进制，代码与文档经 MCP 提交，实际截图和视频按用户授权使用标准 Git 上传。没有将登录凭据写进工程。
