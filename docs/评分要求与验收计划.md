## 5. 模块测试计划

测试使用确定的模拟输入。下表的实际结果目前均为“未执行”，实现后记录实际输出、通过或失败、日志路径及代码版本。

| 编号 | 类型 | 模拟输入或操作 | 预期结果 |
| --- | --- | --- | --- |
| M01 | 正常 | 从可行走区域向空地移动 | 坐标按方向更新 |
| M02 | 边界 | 角色向墙壁或书架边缘移动 | 角色不进入障碍或越出地图 |
| M03 | 异常 | 非法坐标、非法方向或异常移动步长 | 拒绝无效输入或恢复安全状态 |
| I01 | 正常 | 在调查范围内调查可用物件 | 返回文本并按条件收集线索 |
| I02 | 边界 | 分别位于交互距离阈值内、阈值上和阈值外 | 与约定的距离规则一致 |
| I03 | 异常 | 调查不存在的物件，或远距离触发调查 | 返回明确结果，进度不被非法修改 |
| C01 | 边界 | 重复调查同一线索 | 线索集合不出现重复条目 |
| P01 | 正常 | 提交从线索推导出的正确密码 | 解锁目标门并保存状态 |
| P02 | 边界 | 空密码、长度不足、长度超出约定 | 给出输入反馈，不推进剧情 |
| P03 | 异常 | 错误密码或不支持的字符 | 不解锁，允许重新尝试 |
| E01 | 正常 | 分别满足两个结局的条件并作出对应选择 | 到达各自结局，更新结局记录 |
| E02 | 异常 | 缺少额外线索时请求隐藏结局 | 阻止该选择或提示缺少条件 |
| S01 | 正常 | 保存有效进度后重新加载 | 场景、角色位置、线索、谜题、结局记录一致 |
| S02 | 边界 | 首次启动、没有存档 | 显示新游戏入口，不伪造继续游戏进度 |
| S03 | 异常 | 损坏 JSON、错误存档版本、非法坐标 | 显示合理提示，按规则安全恢复 |
| S04 | 异常 | 存储替身模拟写入或 flush 失败 | 显示保存失败，不能误报成功 |

物理判定测试使用可控地图和坐标；剧情测试使用预置进度；存储测试使用 Mock 存储接口。测试设计以风险和功能为依据，不追求用例数量。
