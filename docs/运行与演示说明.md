# 运行与演示说明

## 第一次打开

在 DevEco Studio 选择 Open，打开工程根目录（能看到 build-profile.json5、entry 和 AppScope），等待依赖同步。启动 API 17 的 Huawei_Phone 模拟器，工具栏选择 entry 与模拟器，点击运行。实际使用的 DevEco 版本是 5.0.13.240。

看到首页后点击「开始探索」。本机测试后可能已经有进度与结局收藏，可使用「重新开始」清空本轮；结局收藏会保留。新设备第一次安装没有测试存档。

## 基本操作

按住屏幕方向键移动，松开停止；桌面、书架和墙壁不可穿过。靠近物件后点击调查，读完弹窗后继续探索。右侧门依次通往书架区、阅览区；资料室在阅览区上方。切换回声查看过去，点击线索入口整理发现。离开游戏再回来，首页可继续进度。

## 建议课堂演示顺序

1. 展示首页、玩法说明和开始入口。
2. 前台移动、碰撞、靠近调查；切回声发现另一条线索。
3. 展示手册；通过门走到书架区、阅览区。
4. 展示密码错误反馈、根据线索推导后解锁并进入资料室。
5. 展示信件与结局分支；退出重启验证恢复。
6. 打开 GitHub，展示需求先于实现的 Commit、模块与测试结果、截图和视频。

## 命令行复查（Windows PowerShell）

```powershell
.\scripts\test.ps1 -DevEcoHome 'D:\Harmony\DevEco Studio'
.\scripts\build.ps1 -DevEcoHome 'D:\Harmony\DevEco Studio'
& 'D:\Harmony\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe' list targets
& 'D:\Harmony\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe' -t 127.0.0.1:5555 install -r '.\entry\build\default\outputs\default\entry-default-unsigned.hap'
& 'D:\Harmony\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe' -t 127.0.0.1:5555 shell aa start -a EntryAbility -b com.wxrsunny.zerohourlibrary
```

如果安装路径或设备编号不同，替换为自己的实际值。脚本优先使用 DevEco 自带工具。个人证书、本地 SDK 路径和缓存不放在源码包内；真机需要另行配置签名。
